# 던전 러너 (Dungeon Runner) - 기획서 분석

> 원본 문서: `docs/기획/2주_로그라이크_기획서.docx`

## 게임 개요

| 항목 | 내용 |
|------|------|
| 장르 | 탑다운 액션 로그라이크 (서바이벌 방식) |
| 플랫폼 | PC (키보드/마우스) |
| 제작 기간 | 2주 (진행 중) |
| 아트 스타일 | 카툰 스타일 (AI 생성 리소스, 준비 중) |
| 목적 | 개인 취미 프로젝트 |

## 게임 루프

> ⚠️ 기획 변경: 방 기반 던전 → **무한 서바이벌** 방식으로 전환
```
게임 시작 → 무한 적 스폰 (가중치/시간 해금) → 레벨업/강화 선택 → 보스 등장 (60초마다)
                                                                              ↓ 사망 시
                                                                          처음부터 리스타트
```

## 구현 시스템 목록

### 1. 핵심 전투 시스템 ✅ 완료

**플레이어**
- [x] WASD 이동 + 마우스 방향 조준 + 클릭 공격
- [x] 기본 무기: 총알형 투사체 발사 (데미지, 관통, 연사속도, 속도 스탯화)
- [x] 체력 + 대시: 간단한 생존 메커닉
- [x] 피격 시 체력바 흔들림
- [x] 카메라 쉐이크

**적 AI 4종** (기획 대비 1종 추가)
- [x] ChaserEnemy: 기본 추적형
- [x] RangedEnemy: 원거리형 (거리 유지 + 투사체 발사)
- [x] DashEnemy: 돌진형 (예고 깜박 → 돌진)
- [x] SummonerEnemy: 소환형 (미니언 2마리 소환)

**보스** ✅ 완료
- [x] 보스 1종, 3페이즈 패턴
  - 1페이즈 (HP 100~50%): 추적 + N방향 탄막
  - 2페이즈 (HP 50~25%): 이동속도 증가 + M방향 탄막
  - 3페이즈 (HP ~25%): 미니언 소환 + 전방향 난사
- [x] 보스 HP 바 UI 표시
- [x] 60초마다 등장, 등장 시 일반 스폰 중지
- [ ] 보스 등장 경고 연출 (미구현)

### 2. 맵 생성 시스템 ⏳ 미구현

> ⚠️ 서바이벌 방식으로 전환으로 인해 낮은 우선순위로 조정
- [ ] 고정된 방 레이아웃 프리팹 5~7개
- [ ] 노드 기반 맵 (Slay the Spire 방식)
- [ ] 방 타입: 일반 전투 → 정예 전투 → 상점 → 보스
- [ ] Scriptable Object 기반 노드 시스템

### 3. 로그라이크 진행 요소 🔄 일부 구현

**전투 보상 (레벨업 시 강화 선택)**
- [x] 강화선택지 8종 (3개 랜덤 제시, 1개 선택)
  - MaxHp, HpRestore, MoveSpeed, FireRate
  - BulletDamage, BulletSpeed, Pierce, DashCooldown
- [x] 레벨업 시 게임 일시정지 + 선택 UI
- [x] XP 설계: 킬당 +10 XP, 레벨업 XP: 50, 70, 90... (+20 증가)
- [ ] 향후 추가 강화: 멀티샷, 흡혈, 폭발, 이동속도 연동 데미지

**메타 진행** ⏳ 미구현
- [ ] 영구 화폐로 시작 스탯 강화
- [ ] 새 무기/캐릭터 언락

**난이도 스케일링**
- [x] 시간에 따라 스폰 간격 감소 (점점 빨라짐)
- [x] 시간별 적 종류 해금 (unlockTime)
- [x] 최대 활성 적 50마리 제한

### 4. UI/메뉴 🔄 일부 구현

- [ ] 메인 메뉴 (시작, 업그레이드, 설정)
- [x] 인게임 HUD: 체력바, XP바, 타이머, 레벨
- [x] 보스 HP 바 (보스 등장 시 표시)
- [x] 보상 선택 UI: 카드 형식
- [x] 사망 화면: 생존시간, 킬 카운트, 다시 시작

### 5. 사운드/밸런스 ⏳ 미구현

- [ ] 기본 효과음: 공격, 피격, 사망
- [ ] 배경음악: 1~2트랙
- [ ] 플레이테스트 & 밸런싱

### 6. 주스(Juice) 이펙트 ✅ 완료

- [x] 적 피격 시: 하얗게 번쩍 + 넉백
- [x] 적 사망 시: 파티클 이펙트
- [x] 레벨업 시: 캐릭터 주변 링 이펙트 (일시정지 중에도 동작)
- [x] 카메라 쉐이크 (적 처치 시)
- [x] 플레이어 피격 시 체력바 흔들림
