## 구현 상세

### 오브젝트 풀링 시스템
**EnemySpawner에 통합** (Assets/Scripts/Logic/System/EnemySpawner.cs)
- Dictionary + Lazy Loading 방식
- `_pools`: 타입별 Queue<EnemyBase> 관리
- `_instanceToPoolKey`: 활성 인스턴스 추적 (InstanceID → PoolKey)
- `GetEnemy()`: 풀에서 가져오거나 새로 생성
- `ReturnEnemy()`: 비활성화 후 풀로 반환
- 초기 로딩 부담 없음 (필요시 생성)

**EnemyBulletPool** (Assets/Scripts/Logic/System/EnemyBulletPool.cs)
- 적 총알 전용 풀링 시스템
- Singleton 패턴
- 활성 총알 리스트 관리

**적 클래스 수정**
- `EnemyBase.Die()`: EnemySpawner.ReturnEnemy() 호출
- `EnemyBase.OnReturnToPool()`: 상태 초기화 (체력, 시각효과 등)
- `EnemyBullet.ReturnToPool()`: EnemyBulletPool로 반환
- 모든 하위 적 클래스 풀링 지원 (RangedEnemy, DashEnemy, SummonerEnemy)

### 시각 효과

**적 피격 플래시** (EnemyBase.cs)
- 피격 시 색상 흰색으로 변경 (0.1초)
- Coroutine 기반 HitFlash()
- 풀 반환 시 원래 색상 복구

**사망 파티클** (DeathParticle.cs)
- Quad primitive 기반 파티클 생성
- 적 색상 상속
- 방사형 속도 (8개)
- 중력 적용 + 페이드 아웃 (1초)

**레벨업 이펙트** (LevelUpEffect.cs)
- Sphere primitive 기반 확장 링
- 플레이어 위치에 생성
- 스케일 확대 (0.5f → 3f) + 페이드 아웃 (0.5초)
- Time.unscaledTime 사용 (일시정지 중에도 동작)
