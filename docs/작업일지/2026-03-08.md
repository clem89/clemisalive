## 구현 상세

### BossEnemy (Assets/Scripts/Logic/Enemy/BossEnemy.cs)
- EnemyBase 상속
- 3페이즈 시스템 (HP 비율로 자동 전환)
  - 1페이즈 (HP 100~50%): 플레이어 추적 + N방향 탄막
  - 2페이즈 (HP 50~25%): 이동속도 증가 + M방향 탄막, 색상 변화 (주황)
  - 3페이즈 (HP ~25%): 미니언 소환 + 전방향 탄막, 색상 변화 (빨강)
- Inspector 조정 가능 항목:
  - `phase1/2MoveSpeed`: 페이즈별 이동속도
  - `bulletCountPhase1/2/3`: 페이즈별 탄막 개수
  - `phase3SummonInterval`: 3페이즈 미니언 소환 주기
- 사망 시 GameManager.OnBossKilled() 호출 후 Destroy

### GameManager (Assets/Scripts/Logic/System/GameManager.cs)
- 보스 등장 타이머 추가
  - `bossSpawnInterval`: 보스 등장 주기 (기본 60초, 조정 가능)
  - `bossKillXpReward`: 보스 처치 XP 보상 (기본 100)
- CheckBossSpawn(): 생존 시간 기준으로 보스 자동 등장
- OnBossKilled(): 보스 처치 시 일반 스폰 재개 + XP 지급

### EnemySpawner (Assets/Scripts/Logic/System/EnemySpawner.cs)
- `_isBossActive` 플래그 추가
- `SetBossActive(bool)`: 보스 활성 중 일반 몬스터 스폰 중지

### HudUI (Assets/Scripts/UI/HudUI.cs)
- 보스 HP 바 UI 연동
  - `bossHpGroup`: 보스 등장 시 활성화, 사망 시 비활성화
  - `bossHpSlider`: 실시간 HP 비율 표시
  - `bossHpText`: "현재HP / 최대HP" 텍스트 표시
- ShowBossHp(BossEnemy), HideBossHp() 메서드
