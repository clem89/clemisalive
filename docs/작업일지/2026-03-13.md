## 구현 상세

### BossWarningUI
- Singleton (Lazy Initialization, 비활성 오브젝트 탐색 방식)
- `Show()` 호출 시 코루틴으로 텍스트 페이드인 → 비네트 빨간 플래시 → 페이드아웃 후 자동 비활성화
- `displayDuration`(2.5초), `fadeDuration`(0.4초), `vignetteFlashCount`(4회) Inspector 설정 가능
- `Time.unscaledDeltaTime` 사용으로 게임 일시정지 시에도 정상 작동

### GameManager - 보스 스폰 경고 연동
- `_isBossSpawning` 플래그 추가로 경고 연출 중 중복 스폰 방지
- `SpawnBossWithWarning()` 코루틴: BossWarningUI 표시 → 2.5초 대기 → 실제 스폰
- `Start()`에서 gameOverUI, levelUpUI, BossWarningUI 초기 비활성화 처리

### GameOverUI - 메인 메뉴 버튼
- `mainMenuButton` 필드 추가 (null 체크로 없어도 안전)
- `GoToMainMenu()`: TimeScale 복구 후 `"MainMenuScene"` 로드

### MainMenuUI
- 시작 버튼: `"GameScene"` 로드
- 종료 버튼: 에디터에서는 `EditorApplication.isPlaying = false`, 빌드에서는 `Application.Quit()`
