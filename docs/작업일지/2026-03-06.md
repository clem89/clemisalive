## 구현 상세

### EnemyBase (Assets/Scripts/Logic/Enemy/EnemyBase.cs)
- 모든 적의 공통 기반 추상 클래스
- 공통 처리: TakeDamage, Die, OnTriggerStay2D (접촉 피해)
- 하위 클래스: Enemy, RangedEnemy, DashEnemy, SummonerEnemy

### 적 3종

- **DashEnemy**: 쿨다운(3s) 후 사거리(5f) 이내 접근 시 0.8s 예고(빨간 깜박) → 돌진(14f, 0.3s)
- **SummonerEnemy**: 느린 이동, 4초마다 추적형 미니언 2마리 소환

### EnemySpawner (Assets/Scripts/Logic/System/EnemySpawner.cs)
- Inspector의 List<EnemySpawnEntry>로 프리팹 직접 참조
- 각 항목: prefab(EnemyBase), weight(확률 가중치), unlockTime(등장 해금 시간)
- 초기 JSON/Resources.Load 방식 → Inspector 방식으로 변경

### 폴더 구조 재편 (Assets/Scripts/Logic/)
```
Logic/
├── Character/  ← Character.cs, Bullet.cs
├── Enemy/      ← EnemyBase, Enemy, RangedEnemy, DashEnemy, SummonerEnemy, EnemyBullet
└── System/     ← GameManager, LevelSystem, BulletPool, CameraFollow, EnemySpawner, InfiniteBackground
```
