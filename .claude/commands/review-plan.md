# 기획서 검토 및 업데이트

다음 순서대로 기획서를 현재 구현 상태와 대조하여 업데이트하세요.

## 1단계: 현재 구현 상태 파악
- `Assets/Scripts/` 폴더의 파일 목록 확인
- 최근 작업일지(`docs/작업일지/`) 읽기
- 필요한 경우 주요 스크립트 파일 읽기

## 2단계: 기획서 읽기
- `docs/기획/기획서_분석.md` 파일 읽기

## 3단계: 대조 및 업데이트
파악한 구현 상태를 기획서와 비교하여 다음 항목을 업데이트하세요:

- **구현 완료 항목**: `✅ 완료` 표시 및 상세 내용 반영
- **진행 중 항목**: `🔄 일부 구현` 표시
- **미구현 항목**: `⏳ 미구현` 유지
- **기획 변경 사항**: 실제 구현과 달라진 기획 내용 명시 (⚠️ 기획 변경)
- **현재 프로젝트 상태 테이블**: 최신 날짜와 상태로 업데이트
- **남은 작업 우선순위**: 현재 시점 기준으로 재정렬

## 4단계: 저장
업데이트된 내용을 `docs/기획/기획서_분석.md`에 저장하세요.

## 5단계: 변경 요약 보고
어떤 항목이 변경되었는지 사용자에게 간략히 알려주세요.
